# Ricky Liu Portfolio

A single-screen portfolio homepage with an interactive project folder, plus Ricky Liu's four complete case studies.

The folder cards link to:

- SkyTab Onboarding
- Intelligence Inbox
- Koto by Toyota
- Shift4 Kiosk

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

For example:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
